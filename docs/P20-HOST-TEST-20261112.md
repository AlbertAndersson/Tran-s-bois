# P20 – beställt skyddat iPhoneprov 2026-11-12

Albert har beställt installation även på avsedd production-hosting för fullt
test. Detta gäller aktuell granskad release med kvarvarande skydd, syntetiska
köp och testbetalningar; ingen Stripe live, extern mail eller publik DNS-cutover.

Production uppgraderas stängd med oförändrad produktionsdatabas. Fulla köp
provas på separat skyddad socen-testyta mot den explicita syntetiska
databasen `socen_se_db`, aldrig mot `socen_se_db_BoIS_prod`. Befintliga
testdata säkerhetskopieras före ett eventuellt nytt isolerat testfixture.
Staging på alberiq.se och dess äldre gymkvot ska bevaras.

Previewflaggan `p20Preview` ger S/M/L, kalenderår, lagutlämning och tydlig
testmärkning i UI. API validerar storlekar mot variantens katalogmetadata;
historisk katalog utan flaggan använder tidigare storlekar. Månadsbatchens
status visas som månadsdag inväntas, inte den äldre antalströskeln.

Workflow `simply-deploy-bois-p20-test.yml` använder befintliga stagingsecrets,
verifierad SSH-hostnyckel och färskt komplett SQL-/runtime-/auth-/webbarkiv.
Ingen seed eller kvotreset körs. Endast S/M/L-metadata på befintlig tröjvariant
ändras; äldre order, betalningar och medlems-/gymdata jämförs oförändrade.
Ny public-katalog växlas först efter verifierad backup; äldre katalog bevaras.

Faktiska SHA, backuper, körningar, URL:er och verifieringsutfall registreras
efter genomförandet. Detta dokument i sig är inte ett utfört deploymentbevis.
